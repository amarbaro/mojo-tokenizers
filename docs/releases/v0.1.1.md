## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
A Hugging Face `tokenizer.json` runtime for Mojo: byte-level BPE (GPT-2, Llama 3, Qwen), WordPiece with BertNormalizer (BERT) and Unigram with a
Precompiled normalizer (T5, XLM-R). `Tokenizer(path)`, `encode(text)`, `decode(ids)`; ids equal the Python `tokenizers` crate's. Mojo 1.2 on Linux;
`src/json` and `src/uregex` are vendored, so a clone builds with `mojo run -I src`.
