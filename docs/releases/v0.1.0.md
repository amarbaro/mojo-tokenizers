## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
A Hugging Face `tokenizer.json` runtime for Mojo: byte-level BPE (GPT-2, Llama 3, Qwen), WordPiece with BertNormalizer (BERT) and Unigram with a
Precompiled normalizer (T5, XLM-R). `Tokenizer(path)`, `encode(text)`, `decode(ids)`; ids equal the Python `tokenizers` crate's. Mojo 1.2 on Linux;
`src/json` and `src/uregex` are vendored, so a clone builds with `mojo run -I src`.

## Highlights

- Ids and decodes identical to the `tokenizers` 0.23.3 crate on 6 real tokenizer files x 2000 generated texts (ASCII, 14 scripts, emoji, whitespace runs, numbers, added tokens).
- Encoding 1 MB is 2.5 to 4 times faster than the crate through Python (80 to 140 ms against 292 to 392 ms), with less memory.
- An unsupported model, normalizer or pre-tokenizer raises at load; it never mis-tokenizes.

## Changes

### Added
- Byte-level BPE with a flat packed merge table and a heap merge, `ignore_merges`, array or string merges, per-piece cache.
- WordPiece with BertNormalizer (clean, CJK spacing, accent stripping, lowercase) and the BERT pre-tokenizer and decoder cleanup.
- Unigram (Viterbi) with the sentencepiece Precompiled normalizer, Replace, WhitespaceSplit and Metaspace.
- Added tokens cut out of the text first, with `lstrip` and `rstrip`.
- `scripts/check.sh` (oracle gate), `scripts/selfcheck.sh` (10 mutants), `scripts/bench.sh`, `recipe.yaml`.

## Known limits

- `NFC` normalizers are accepted but not applied: feed NFC text. Other normalizers, `Split` behaviors other than Isolated, `add_prefix_space`, Metaspace `prepend_scheme: first` raise.
- Truncation, padding, post-processing and `single_word` are ignored.
- The BERT tables are Unicode 16.0.0, uregex 18; a code point assigned in between can differ from the crate.
- `src/tokenizers/tokenizer.mojo` is 594 code lines (`mojo-loc`); the 400-line budget was not met (`n1-report.md`).
- The recipe was generated, not built with rattler-build; the fixtures' upstream URLs in `tests/fixtures.txt` were not fetched except T5. UNVERIFIED.
